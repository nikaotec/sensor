# Codebase Structure

**Analysis Date:** 2026-05-07

## Directory Layout

```
sensor/                              # Project root - IoT Sensor Monitoring System
├── .planning/codebase/              # Codebase mapping documents
├── dashboard/                       # React frontend application
├── esp32/                           # ESP32 firmware (Arduino C++)
├── evolution-api-main/             # WhatsApp API server
├── docs/                            # Project documentation
├── test_env/                        # Testing environment files
├── *.json                           # n8n workflow files
├── *.sql                            # Database migrations and schema
├── *.py                             # Utility scripts
└── *.md                             # Project documentation files
```

## Directory Purposes

**Root Level:**
- Purpose: Project root containing all subsystems
- Contains: n8n workflows, database schemas, documentation, scripts
- Key files: `mqtt receive.json`, `supabase_schema.sql`, `gerador-relatorios-pdf.json`

**`dashboard/`:**
- Purpose: React single-page application for device monitoring
- Contains: Frontend code, build configuration, server
- Key files: `package.json`, `vite.config.ts`, `server.js`, `src/App.tsx`

**`esp32/`:**
- Purpose: ESP32-C3 microcontroller firmware
- Contains: Arduino C++ source files and headers
- Key files: `esp32.ino`, `Config.h`, `AlertManager.cpp`

**`evolution-api-main/`:**
- Purpose: Evolution API WhatsApp integration server
- Contains: Node.js API server (git submodule or external)
- Key files: (external package structure)

**`.planning/codebase/`:**
- Purpose: Codebase mapping documentation for GSD agents
- Contains: ARCHITECTURE.md, STRUCTURE.md, STACK.md, INTEGRATIONS.md
- Key files: Generated by codebase mapper

## Key File Locations

**Entry Points:**
- `dashboard/src/main.tsx`: React application entry point (renders App)
- `dashboard/src/App.tsx`: Main React component with routing and state
- `dashboard/server.js`: Express server for production API proxy
- `esp32/esp32.ino`: ESP32 firmware main loop

**Configuration:**
- `dashboard/package.json`: NPM dependencies and scripts
- `dashboard/vite.config.ts`: Vite build configuration
- `dashboard/.env`: Environment variables (Supabase URL/key, Firebase config)
- `dashboard/tsconfig.json`: TypeScript configuration
- `supabase_schema.sql`: Database schema and indexes

**Core Logic:**
- `dashboard/src/components/`: React UI components
- `dashboard/src/hooks/`: Custom React hooks for data fetching
- `dashboard/src/contexts/`: React context providers (Auth, Tenant, Notifications)
- `esp32/*.ino`, `esp32/*.cpp`, `esp32/*.h`: Firmware modules
- `*.json`: n8n workflow definitions

**Testing:**
- `dashboard/src/tests/`: Test files and utilities
- `test_env/`: Testing environment configuration

## Naming Conventions

**Files:**
- **Workflows:** `n8n_<function>.json` (e.g., `n8n_hourly_telemetry.json`)
- **SQL:** `<action>_<table>.sql` (e.g., `add_telemetry_columns.sql`)
- **Components:** PascalCase with descriptive name (e.g., `DeviceDetails.tsx`, `Alerts.tsx`)
- **Hooks:** `camelCase` with `use` prefix (e.g., `useMqttData.ts`, `useSupabaseData.ts`)
- **Config:** Descriptive (e.g., `config.ts`, `firebaseConfig.ts`)

**Directories:**
- **Components:** Plural (e.g., `components/`, `hooks/`, `contexts/`)
- **Feature folders:** Singular (e.g., `dashboard/`, `esp32/`, `docs/`)

**Variables/Functions:**
- **React components:** PascalCase (e.g., `DeviceList`, `ManagerPanel`)
- **Hooks:** camelCase starting with `use` (e.g., `useMqttData`, `useTelemetryData`)
- **n8n nodes:** PascalCase (e.g., `Parse Payload`, `Filter Periodic`)
- **Supabase tables:** snake_case (e.g., `devices_status`, `telemetry`, `events`)

## Where to Add New Code

**New Feature (Frontend):**
- Primary code: `dashboard/src/components/` or `dashboard/src/hooks/`
- Tests: `dashboard/src/tests/`
- Config: `dashboard/package.json` (add dependency)

**New n8n Workflow:**
- Implementation: Root directory as `n8n_<name>.json`
- Configuration: Add credentials in n8n UI

**New ESP32 Module:**
- Implementation: `esp32/` directory as `.cpp` or `.h` files
- Include: Add `#include` in `esp32.ino`

**New Database Table:**
- Schema: `supabase_schema.sql` (append new table definition)
- Migration: New `add_<feature>_table.sql` file

**Utilities:**
- Shared helpers: `dashboard/src/services/` or `dashboard/src/utils/`
- Scripts: Root level `*.py` for backend utilities
