# Dashboard VPS Deployment Plan

## Goal
Prepare the React/Vite dashboard to be published on a VPS under the domain `www.nikaotech.com`. The goal is to allow the application to run smoothly with simple `npm` commands, exactly as it works in the development environment.

## Current Architecture Analysis
The current dashboard uses Vite and relies on a local Vite development server plugin (`configureServer`) to intercept `POST /api/sensors` requests and save them to `src/data/telemetry.json`.
This approach **does not work** in a standard production build (`npm run build`) because the Vite dev server is not used in production.

## Proposed Strategy

To ensure it works on a VPS seamlessly ("só enviar e rodar"):
1. **Create a Production Node.js Server (`server.js`)**:
   We will build a simple Express.js server that serves two purposes:
   - Serves the static files generated by `npm run build` (`/dist`).
   - Replicates the `/api/sensors` POST endpoint currently inside `vite.config.ts`, so the dashboard continues to receive and save telemetry data in production.

2. **Update `package.json` Scripts**:
   - `build`: Will build the Vite project.
   - `start`: Will run `node server.js` to serve the production build and the API on the VPS.
   - Add `express` and `cors` as dependencies.

3. **Domain Configuration (`www.nikaotech.com`)**:
   - We will configure the Express app to listen on the appropriate port (e.g., 80 or 3000). On the VPS, it's recommended to proxy port 80 to this Node server, or run the Node server directly on port 80 if permissions allow.
